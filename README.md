# Nibbana Garden

Homely comfort. Single-file website for Nibbana Garden, Eldoret.

- `index.html` holds everything (HTML, CSS, JS). Edit the `CONFIG` object at the top of the script for phone, hours, menu, rooms and reels.
- Set `embedMode: true` in CONFIG when live so Instagram reels play on the page.
- Placeholders to fill: `[EMAIL]`, `[OPENING HOURS]`, `[POOL HOURS]`, `[POOL FEES]`, `[CONFERENCE CAPACITY]`, `[WEEKLY PROGRAMME]`, room rates and menu prices.
